# Learning order

## Phase 1 — understand the design
1. Read the project goal.
2. Draw the ER diagram.
3. Understand primary key / foreign key.
4. Understand one-to-many and many-to-one.

## Phase 2 — create the Spring project
5. Create Maven project.
6. Add Web, JPA, Security, Validation, MySQL, Lombok and OpenAPI dependencies.
7. Run the empty application.

## Phase 3 — persistence
8. Build entities.
9. Add enums.
10. Map relationships.
11. Run and inspect generated tables.

## Phase 4 — API architecture
12. Repository layer.
13. Service layer.
14. Controller layer.
15. DTOs.
16. Validation.

## Phase 5 — authentication
17. Password hashing.
18. UserDetailsService.
19. AuthenticationManager.
20. JWT generation.
21. JWT filter.
22. Role-based authorization.

## Phase 6 — quality
23. Global exception handling.
24. Swagger.
25. Test APIs in Swagger/Postman.

## Phase 7 — containerization
26. Build the JAR.
27. Build Docker image.
28. Run with Docker Compose.
29. Pass configuration through environment variables.

## Phase 8 — deployment
30. Push source to GitHub.
31. Push image to Docker Hub if desired.
32. Provision a hosted relational database.
33. Deploy the backend as a web service/container.
34. Configure environment variables.
35. Verify public API/Swagger endpoint.
